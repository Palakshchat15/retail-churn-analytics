Honest discussion:
This is a non-contractual retail dataset with no explicit cancellation event, so churn is inferred from a 6-month outcome window with no positive net sales. The headline outcome window (2011-06-10 -> 2011-12-09) contains the Nov/Dec Christmas peak, so its churn rate is seasonally low; the same definition one year earlier gives 48.4%. The out-of-time check is the better estimate of how a model trained on past data performs on a later period: AUC transfers reasonably, but precision/recall at the 0.5 threshold depend on the base rate the model was trained on. The model has no visibility into external factors (marketing, competitors, stockouts). These numbers are reported exactly as computed.
